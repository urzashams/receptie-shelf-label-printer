# Receptie Shelf Label Printer

Aplicație statică pentru etichetele de rând, deschidere, poliță și cutie. Folosește aceeași imprimare Bluetooth Niimbot și același format de etichetă ca aplicația Receptie.

- Fără cutii: `Rând,Deschidere,Poliță`, câte o etichetă pentru fiecare poliță de la 1 până la numărul ales.
- Cu cutii: `Rând,Deschidere,Polița aleasă,Cutia`, câte o etichetă pentru fiecare cutie de la 1 până la numărul ales.

Pagina necesită HTTPS și un browser cu Web Bluetooth. La prima folosire, browserul cere alegerea imprimantei; după autorizare, aplicația încearcă reconectarea automată.
